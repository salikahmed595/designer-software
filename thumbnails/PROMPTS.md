# Prompts for AI-generated thumbnails

Paste each prompt into your image generator, pick the result that reads most clearly at small size, and save it in this folder with the file name shown (PNG, JPG or WebP). The app shows it on that card automatically.

- Use a **landscape 3:2** size (for example 1200 x 800). The app crops to fit.
- These are examples to help designers recognise a card. They are not client work, so keep them generic.
- Check the licence of your generator allows this use, and review each image before saving it.
- The art-style prompts all use the same character on purpose, so the styles are easy to compare side by side.
